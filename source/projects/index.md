<h2>Project Akari</h2>
<p>Akari 取自日文「あかり」，意为光。这是一个个人独立完成的学习项目，包含书稿写作（《函数与导数》《高中数学之旅》）和配套 Web 学习工具平台（Akari Web）的全栈开发。平台基于 React / Next.js / TypeScript / Tailwind CSS，部署在 Cloudflare Workers 上，提供课程、笔记、记忆卡片、题库和社区功能。书稿使用 XeLaTeX 排版，基础版本免费开放。项目的服务器和运营成本靠书的销售收入以及开发者个人的工作收入覆盖。从内容创作、UI 设计、前后端开发到基础设施运维，均由开发者独立主导。</p>
